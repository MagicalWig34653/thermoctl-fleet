# Fleet UI Roles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freely definable roles built from a fixed permission catalogue, enforced server-side per UI route, with web management of roles and invitation-based account creation.

**Architecture:** New tables `ui_roles`, `ui_role_permissions`, `ui_invitations` plus `ui_users.role_id` (migration 0020, existing users become "Administrator"). A `require_permission(name)` dependency wraps `require_ui_user` and reads permissions from the database per request. A route-coverage test fails when a UI route has no declared permission.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, Jinja2 templates, pytest, Argon2 (`fleet.ui_auth.hash_password`), existing `fleet.totp_crypto`.

Spec: `docs/superpowers/specs/2026-10-16-ui-roles-design.md`.

## Global Constraints

- Agent stays the security boundary (CLAUDE.md principle 5): do not touch `agent/`, `protocol/`, `CommandType`.
- Permission names are fixed in code; unknown names read from the DB are ignored (fail closed). `view` cannot be removed from a role.
- Invitation token: `secrets.token_urlsafe(32)`, 24 h validity, single use, only the SHA-256 hash (`fleet.storage.hash_token`) is stored.
- Password policy: `fleet.ui_auth.MIN_PASSWORD_LENGTH` (12). TOTP secret stored encrypted (`encrypt_totp_secret(secret, user_id, key)`).
- Last account holding `users.manage` can be neither deleted, locked nor demoted; users cannot change their own role; a role in use cannot be deleted.
- Auth-logic tasks (1-4) are done in the main session; tasks 5-6 go to an agent with cross-review. Tests per task; `ruff check .`, `mypy protocol fleet agent tools`, full `pytest -o addopts='' --no-cov -q` before every merge. Never run repo-wide `ruff format`.

```python
# fleet/permissions.py
"""Fixed permission catalogue for the fleet UI (sim finding F11)."""
from __future__ import annotations

from collections.abc import Iterable
from enum import StrEnum


class Permission(StrEnum):
    VIEW = "view"
    FAULTS_ACKNOWLEDGE = "faults.acknowledge"
    COMMANDS_SEND = "commands.send"
    BACKUPS_MANAGE = "backups.manage"
    TENANT_CHANGE = "tenant_change"
    DESIRED_STATE_EDIT = "desired_state.edit"
    PILOT_MODE_SET = "pilot_mode.set"
    INVENTORY_MANAGE = "inventory.manage"
    ROLLOUTS_MANAGE = "rollouts.manage"
    USERS_MANAGE = "users.manage"


ALL_PERMISSIONS: frozenset[Permission] = frozenset(Permission)

ADMIN_ROLE_NAME = "Administrator"


def parse_permissions(names: Iterable[str]) -> frozenset[Permission]:
    """Unknown names are dropped (fail closed)."""
    known = {p.value: p for p in Permission}
    return frozenset(known[n] for n in names if n in known)
```

```python
def require_permission(permission: Permission) -> Callable[..., AuthenticatedUiSession]:
    def dependency(
        authenticated: AuthenticatedUiSession = Depends(require_ui_user),  # noqa: B008
        storage: Storage = Depends(get_storage),  # noqa: B008
    ) -> AuthenticatedUiSession:
        granted = storage.get_ui_role_permissions(authenticated.user.role_id)
        if permission not in granted:
            raise HTTPException(status_code=403, detail="Missing permission.")
        return replace(authenticated, permissions=granted)

    dependency.__ui_permission__ = permission  # type: ignore[attr-defined]  # read by the coverage test
    return dependency
```

`AuthenticatedUiSession` gains `permissions: frozenset[Permission] = frozenset()` (dataclass default) so existing constructors keep working. The existing HTML 403 handling for `/ui/` (see `fleet/hardening.py` handler pattern) must render a plain-language page; add template `fleet/templates/ui/forbidden.html` ("Dafür fehlt Ihnen die Berechtigung.") and reuse the `/ui/` Accept-based rendering path.

```python
INVITATION_LIFETIME = timedelta(hours=24)

def create_invitation(storage, username, role_id, created_by, now) -> str:
    name = normalize_username(username)
    if storage.get_ui_user_by_username(name) is not None:
        raise ValueError("Benutzername ist bereits vergeben.")
    token = secrets.token_urlsafe(32)
    storage.create_ui_invitation(
        username=name, role_id=role_id, token_hash=hash_token(token),
        created_by=created_by, created_at=now, expires_at=now + INVITATION_LIFETIME,
    )
    return token

def accept_invitation(storage, raw_token, password, totp_secret, totp_code, now):
    invite = get_open_invitation(storage, raw_token, now)
    if invite is None or len(password) < MIN_PASSWORD_LENGTH:
        return None
    if verify_totp(totp_secret, totp_code, now, None) is None:
        return None
    if not storage.mark_ui_invitation_used(invite.id, now):   # atomic, single use
        return None
    try:
        user = storage.create_ui_user(invite.username, hash_password(password), "", now, role_id=invite.role_id)
    except IntegrityError:
        return None
    storage.set_ui_user_totp_secret(user.id, encrypt_totp_secret(totp_secret, user.id, totp_key()))
    return user
```

`get_open_invitation` compares via the hash lookup (`hash_token(raw)`), returns `None` when `used_at` is set or `expires_at < now`. Guards return fixed German strings.
