Neuer Rollout

Ein Rollout aktualisiert genau einen Dienst (thermoctl oder Zigbee2MQTT oder Mosquitto oder Agent – niemals gemischt) für eine geordnete Liste von Wohnungen. Eine Wohnung dieser Liste ist die Testwohnung dieses Rollouts: markieren Sie sie unten explizit, oder lassen Sie die Markierung weg – dann ist die erste Wohnung der Liste die Testwohnung. Die Testwohnung läuft zuerst; die übrigen Wohnungen frühestens 48 Stunden nachdem die Testwohnung erfolgreich zurückgemeldet hat. Dies ist unabhängig vom Pilotbetrieb-Flag der Wohnung (das weiterhin nur die geräteseitige Freischaltung in agent/ steuert, z. B. für open_access) – eine Wohnung ohne Pilotbetrieb kann ganz normal die Testwohnung eines Rollouts sein.
